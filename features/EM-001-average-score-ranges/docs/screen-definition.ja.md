# 画面に必要な内容 — EM-001

更新日：2026年10月22日。[ベトナム語版](screen-definition.vi.md)に対応する、設計に付随する文書。**Figmaは10月16日・21日にShiteへレビュー依頼済み（[スレッド](https://tryhand.slack.com/archives/C0BRGJA6XDE/p1791290107759389)）。スレッドにShiteの承認はまだない。**

## 1. ルールの設定

登録先項目、平均点の参照元（集計設定・時期・対象集団）、個人点の参照項目、条件と登録値、および判定順を指定する。登録先は数値型または選択肢型。

登録先の値の範囲と条件数を区別する。例えば登録先が1～5でも、マッピングは1・3・5だけを使用できる。条件の追加・削除で登録先の範囲を変更しない。独立した評価段階数の設定や、不一致時の最低評価の自動割当は設けない。

平均点の参照元には授業平均（順位集計で授業毎の集計を使う場合）と科目グループ（「{グループ名}平均」）も含む。選択肢型の登録値セルの先頭は「選択してください」（未使用セル）とし、「(空欄)」（空欄を登録）と区別する。範囲は最大10、1範囲あたりの条件は最大20。設定が大きすぎて保存できない場合は保存時にエラーを表示する。対象時期と平均点の参照元の選択肢は、順位集計の学年・HR設定に関わらず表示する。

## 2. 設定の再表示

保存した参照元、条件、比較演算子、登録値、順序を再表示できること。レイアウト、入力部品、画面遷移はFigma設計時に具体化する。

## 3. 結果の確認

Q4に従い、成績抽出の度数分布表・グラフを使用し、人数確認用の画面は新設しない。2026年10月16日のローカル環境での確認では、数値型・選択肢型（A/B/C）の双方で表とグラフが出力され、人数が一致した。詳細は[context第10節](../CONTEXT.md)を参照。受入判定までに、staging、空欄の結果、およびEM-001の自動計算から成績抽出までの一連の動作を確認する。

参照元や一致した条件を説明する計算履歴の拡張は設計案であり、顧客から個別に要求・承認された画面ではない。
