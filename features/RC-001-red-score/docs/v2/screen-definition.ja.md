## 00 — 概要・読み方

### 目的と利用者

数値の評価項目に1つ以上の赤点ルールを設定し、生徒の最終保存点を判定する。判定結果は成績抽出・成績公開・通知表で共通利用する。赤点判定自体は得点を変更せず、科目合格・進級を自動決定しない。

| 利用者 | できること | 制限 |
| --- | --- | --- |
| 評価項目の設定権限を持つ利用者 | 赤点ルールの追加・編集・並べ替え・削除 | 機能へのアクセス権と対象項目の編集権の両方が必要。通常教員も両権限があれば利用可能 |
| 成績登録者 | 得点の入力・修正・削除。登録処理に従って関連セルを判定 | 許可された授業・科目・生徒・時期・単元に限定 |
| 一括計算の実行権限を持つ利用者 | 許可範囲の集計・計算を実行 | ルール編集権だけで学年全体・学校全体の実行権を得ない |
| 成績抽出・成績公開・通知表の利用者 | 表示設定と判定結果の利用 | 各機能の権限と既存の保存・出力手順を維持 |
| 生徒・保護者 | 公開された成績の閲覧 | 許可された生徒・年度・公開期間・表示範囲に限定。ルールは編集不可 |

**対象：** 整数、小数、単元別の数値項目。A/B/Cや合否の選択型項目を直接赤点判定しない。ただし、選択型項目の値を対象フィルターとして使用し、数値項目の適用対象を絞ることはできる。

### 操作の流れ

1. 数値項目を選択し、赤点ルール一覧を開く。
2. ルールを追加し、適用条件と基準・計算式を入力する。必要な情報が揃ったルールだけを判定に使用する。
3. 上下ボタンで優先順位を調整する。各操作は処理成功時に即時保存する。設定の保存だけでは生徒の赤点結果は更新しない。
4. 成績登録または計算を実行する。平均点・集団得点率を使う場合は、参照する得点入力と集計を完了してから計算を実行する。
5. 完了した共通の判定結果を成績抽出・成績公開・通知表で利用する。表示方法は出力ごとに設定する。

### 構成要素表の読み方

- **必須**は編集対象部分を保存する際の要件。「条件付き」は各行で条件を説明し、「—」はボタン・ラベル・読取専用表示を示す。
- **表示条件**はその画面の操作権限の範囲内で適用する。URLや送信IDの変更で権限を増やすことはできない。
- **操作・結果**は実装で満たすべき動作であり、稼働済みアプリケーションのテスト結果ではない。
- No.は表内の構成要素番号であり、タスクIDではない。操作名は機能を説明し、設計元にある日本語UIラベルはそのまま使用する。
- 同じ画面内のA/B/Cは状態例であり、別画面や手順の区切りとは限らない。
- 例示値やグループ名を、そのまま初期値として設定しない。

**優先順位の例：** 上位が`<20`、下位が`<30`で両方適用可能な場合、25点は上位ルールを使うため非赤点。未完成ルールは下位の完成済みルールの選択を妨げない。

**順序保存 — 既存の自動計算操作を継承する設計案：** 上下ボタン1回につき1回保存を要求する。処理中は追加の並べ替えと画面遷移を受け付けない。保存成功時は新順序と設定保存完了を表示し、再表示・再読込みでも順序を維持する。保存失敗が確認された場合は前回保存順を維持してエラーを表示し、再操作を可能にする。通信断などで保存結果が不明な場合は未確認と案内し、一覧を再取得してから操作を再開する。成功や取消し完了を断定しない。順序変更だけでは生徒を再判定しない。

**削除の扱い：** 再読込みでも削除済みルールを表示しない。削除前から開いていた編集画面から保存しても復活させない。無効状態を保存できることだけを理由に、復元ボタンや有効・無効切替を追加しない。

### 対象フィルターの種類

複数選択では、複数行に分けた場合も同じ種類の値をORで結ぶ。表の異なる種類同士はANDで結ぶ。学校・年度・許可範囲内の有効データだけを表示する。

| 種類 | 選択する値 | 選択数 | 関連項目と解釈 |
| --- | --- | --- | --- |
| 教科 | 学校に設定された教科 | 1つ以上 | 科目とは別種類。両方指定した場合は両条件を満たす必要がある |
| 科目 | 設定範囲内の科目 | 1つ以上 | 同名の別科目をまとめない |
| 学年 | 当該年度の生徒の学年 | 1つ以上 | 例：1年または2年 |
| ホームルーム | 生徒のホームルーム | 1つ以上 | 授業とは別種類。「学級・グループ」として一括りにしない |
| 授業 | 判定する得点セルの授業 | 1つ以上 | 例：ホームルーム1Aと数学Bの授業を指定した場合、両方を満たす必要がある |
| 順位集計グループ | 選択したグループ設定に属するグループ | 1つ以上 | 各行で設定を1つ選んで所属グループを指定。同種類の複数行はOR。対象の絞込みであり平均の参照母集団を変更しない |
| 選択型項目の値 | 選択型項目に定義された値 | 1つ以上 | 各行で項目を1つ選んで値を指定し、項目と値の組合せを維持。別項目を選んでも同種類の行をANDに変えない |

グループ設定または選択型項目を変えた場合、無効になった子の値を解除し、保存前に再選択を求める。別設定の同名値へ置き換えない。

**平均点・集団得点率条件だけを使う場合：** 通常の対象範囲を全対象とし、通常フィルターを追加せず、集計条件と参照元を入力する。`A≥50`と`A<70`だけなら、項目の範囲内で`50≤A<70`のときに適用する。仮の学級や学年フィルターを追加する必要はない。全対象を選んでも集計条件は無視しない。通常フィルターと集計条件の両方がない場合だけ、項目の範囲内で無条件適用とする。通常フィルターで対象限定を選んだまま空ならエラーとし、フィルター入力または明示的な全対象への変更を求める。

### 選択可能な参照元

| 母集団の種類 | 選択できる条件 | 使用する結果 |
| --- | --- | --- |
| 学年 | 既存設定で学年集計が有効 | 選択した設定の該当学年の結果 |
| ホームルーム | ホームルーム集計が有効 | 該当ホームルームの結果 |
| 授業 | 授業集計が有効 | 対象セルの授業の結果。同じ科目の別授業で代用しない |
| 順位集計グループ | 適切なグループ設定が存在 | 名称で選択しIDで保存したグループの結果 |
| 組み合わせグループ | 適切な組合せ設定が存在 | 選択した組合せの結果 |
| 科目グループ | 適切な科目グループ設定が存在 | 科目の個別設定または保存済みデフォルトから特定した母集団の結果 |

最後の3種類は学年・ホームルーム・授業の集計スイッチとは独立する。未設定でも常に全6種類を表示するわけではなく、赤点側に独立した集計スイッチを追加しない。選択可能でも有効な集計結果があるとは限らない。グループやデフォルトが無効になっても同名の別グループや代替参照元を自動選択しない。

### 設定例

| 設定 | 解釈 |
| --- | --- |
| 1年・2年と上級グループを選択 | 1年**または**2年で、**かつ**上級グループに所属 |
| 同じ参照元で平均≥50、平均<70 | `50≤A<70`。40・70は不成立、50・60は成立 |
| 授業Aへ適用し、A+Bの平均を参照 | 判定対象は授業A、平均の参照母集団はA+Bのまま |
| 固定基準30、適用条件が平均≥60 | 適用可否に平均が必要。欠損時に条件を外して全対象へ30を適用しない |

条件と計算式の参照元は独立して保存する。この画面で参照元を変えても基準画面の参照元は変えない。確定済み結果の選択と欠損時の扱いは[共通ルール](#source-policy)を参照。

### 計算式の構成要素

### 入力画面・一覧で確認できる例

| 場面 | 設定 | 結果 |
| --- | --- | --- |
| 得点が基準と同じ | S=30、T=30 | `<`なら非赤点、`≤`なら赤点 |
| 得点率に小数が生じる | M=75、30%、S=22.2、`<` | 処理なし：T=22.5で赤点。整数へ切り捨て：T=22で非赤点 |
| 03-Cの計算式 | A=49.7。1行目A÷2を整数へ切り捨て。2行目は1行目の結果×0.8、処理なし | 49.7÷2=24.85 → 24 → 19.2。S=19.1、`<`で赤点 |
| 処理位置が異なる場合 | 同じ計算で2行目だけを整数へ切り捨て | T=19、S=19.1は非赤点。別設定の例である |
| 負の閾値 | A=15、式A−20 | T=−5は有効。0へ補正しない。非負の得点は非赤点 |
| 負数の端数処理 | −5.2、p=1 | 切り上げは−5、切り捨ては−6 |
| 中間値の四捨五入 | −5.5、p=1 | −6。ちょうど半分は0から離れる方向 |

閾値の代わりに生徒の得点を丸めず、条件選択前に参照平均を切り捨てない。範囲超過値はエラーとし、保存のために桁を自動削減しない。

| CSVによる成績登録 | 登録対象の行・セルと既存の保存単位で同じ判定を適用 |
| 試験・採点結果の連携 | 対応範囲内で実際に書き込むセルを判定。自動算出を実行しないことだけで除外しない |
| 得点を削除して空欄にする | 保存成功直後に空欄とし、そのセルの赤点表示・抽出への寄与を停止。再実行を待たない |
| 定義・項目の満点保存 | 設定を変更するだけで、全校を自動再判定しない |
| 授業別満点選択・既存の一括満点設定 | 許可された既存計算経路が成功した後に結果を更新 |
| 単元別得点の削除・利用停止 | 失われた得点に紐づく結果の利用を停止。0点に変換しない |

各経路は既存画面を使用する。各成績入力画面に赤点判定専用ボタンは追加しない。

**平均点・集団得点率の運用順序：** 自動集計を無効化 → 対象母集団の入力完了 → 緑ボタンの集計完了 → オレンジボタンの計算完了 → エラー・判定不可を確認 → 出力を利用。計算で参照元の得点自体が変わった場合は適切な範囲で再運用する。集計と計算を収束するまで自動反復しない。

**同時更新の例：** 一括処理が29点を読み込んだ後、教員が40点と非赤点を保存した場合、後から完了した旧処理で29点の赤点結果を40点へ付けない。29→40→29や、削除後に29を再入力した場合も旧処理結果を再利用しない。

## 11 — 共通ルール・状態・例

複数画面に共通する規則を説明する章であり、新しい管理画面ではない。状態名は業務上の区分であり、生徒画面にすべての状態ラベルを追加する指定ではない。

### 判定に使用する得点・値

| データ | 使用方法 |
| --- | --- |
| 最終得点S | 計算・得点制限・関連更新後の最終保存値。中間値は使わない |
| 手入力・手修正点 | 自動計算式がない、または実行されない場合も判定対象 |
| 見込点 | 数値は判定対象。見込点フラグは赤点フラグで置き換えない |
| 数値がある未受験 | 未受験フラグだけで数値を赤点判定から除外しない。順位対象外とは別の扱い |
| 0点 | 有効な得点として閾値と比較 |
| 空欄・削除・利用停止 | 0に変換せず、以前の得点の記号を残さない |
| 満点M | 項目・時期の標準 → 有効な単元例外 → 最終的に適用される授業の選択。例：100→40→50なら50 |
| 平均A・集団得点率R | 正しい参照結果の丸め前の値。表示が50でも平均49.99は50未満 |

生徒・学校・年度・授業・項目・時期・単元が異なれば別セルとして扱う。科目・項目の表示名だけで結果を結びつけない。同名項目でも単元が異なれば結果を共用しない。

<a id="source-policy"></a>
### 参照元とルールの選択

1. 完成済みルールを優先順に確認する。集計に依存しないフィルターで対象外と確定すれば、そのルールを除外する。
2. 適用する可能性があるルールで判断材料が不足する場合は判定不可とする。欠損を不一致とみなして下位ルールへ進まない。
3. 最初に一致と確定したルールを選び、その閾値を計算する。参照元不足や式の計算不可でも別ルールを試さない。
4. 全ルールが不一致と判断できる十分な情報がある場合は適用外とする。

参照集計は学校・年度・時期・設定・母集団・科目・項目・単元を一致させる。該当する確定済み結果を優先し、それがない場合だけ同範囲の最新完了結果を使う。選択した確定済み結果に不足があっても、通常集計・別時期・別グループ・未集計得点・0で代用しない。

条件と計算式の参照元は独立する。同じ参照元を1回の判定内で複数回使う場合は、同一の版と値を使用する。集団得点率は既存集計結果を継承し、個人別得点率の平均を別計算したり、ある生徒の現在の満点を確定済み集計の合計値と組み合わせたりしない。

同じ参照集計で60/100と80/100なら集団得点率は70%で、65%以上の条件を満たす。授業間で満点が異なる場合も既存集計結果を継承し、その違いだけで設定禁止や処理停止にしない。

### 状態と出力への影響

| 状態 | 意味 | 赤点表示・抽出 |
| --- | --- | --- |
| 赤点 | 正常判定し、得点が比較条件を満たす | 出力ごとの設定で強調・抽出 |
| 非赤点 | 正常判定し、得点が閾値条件を満たさない | 赤点効果なし |
| 未判定 | 完了した判定結果がまだない | 赤点記号を付けない。合格とはみなさない |
| 判定不可 | 実行したが参照元・演算対象不足、割合に使用する満点不正、0除算、桁あふれなど | この状態の保存成功時に旧結果の記号・抽出を停止。得点は維持 |
| 適用外 | 全ルールが不適用と確定。再判定時にルールがなくなった場合を含む | 旧赤点結果を停止。ある基準に合格したという結論ではない |
| 得点なし | 空欄・削除・利用停止 | 仮の0や旧記号を使用しない |

「再実行待ち」は設定・参照元が変わっても前回結果がまだ有効な状態を指し、新しい非赤点・判定不可の結論ではない。未判定・判定不可だけを理由に抽出・公開・通知表を止めない。各機能の権限・公開期間・非表示条件は維持する。

### 結果が変わる時点

| 操作 | 保存成功直後 | 次回判定後 |
| --- | --- | --- |
| 基準・比較・対象・優先順位・式・参照元の変更 | 生徒の前回結果を維持し、再実行を案内 | 現在の設定でルール選択・判定 |
| 一部または全ルールの削除 | ルール行は消えるが、生徒の前回結果は維持 | 残存ルールで判定。全削除なら適用外 |
| 得点削除・空欄化 | 直ちに空欄とし、そのセルの赤点記号・抽出への寄与を停止 | 有効な得点が再登録された時に判定。旧セル結果は継承しない |
| 29点から40点への修正 | 保存・判定成功時に40点と40点の結果を揃えて保持 | 遅れて完了した旧処理で上書きしない |
| 集計結果だけの更新 | 前回赤点結果を維持。すべての依存先を自動再判定しない | 確定済み優先規則により参照元を選択 |
| 実行したが閾値を算出できない | 状態保存成功後、旧結果の利用を停止 | 原因修正後の再実行で新しい結論を得る |
| 閲覧・Excel取得・公開・再印刷 | 現在有効な結果を読み、判定データは変更しない | 判定処理を自動開始しない |

保存の技術エラーは判定不可とは区別する。書込みが失敗した場合、得点削除済み・旧結果失効済み・判定成功と表示しない。一括処理の一部が完了した場合は、再実行が必要なエラー範囲を明示する。

### 共通の入力検証

| 項目 | 設計上の規則 |
| --- | --- |
| ルール名 | 前後空白除去後1–255文字。重複可 |
| 固定基準 | 保存時に全適用対象の0..満点以内。小数部3桁以内、999999.999以下 |
| 満点に対する得点率 | 0–100、小数部3桁以内 |
| 平均の比較値・式の固定値／係数 | 有限値、整数部9桁・小数部8桁以内 |
| 集団得点率の比較値 | 0–100、小数部8桁以内 |
| 計算式 | 完成した1–20行。自己・後方・削除済み行を参照不可。固定0での除算を保存不可 |
| 端数処理 | 初期値は処理なし。有効時は桁1–9と方法が必要。閾値・行結果に適用し、生徒の得点を代わりに丸めない |
| 参照元・対象 | 権限・学校・年度が正しく有効。保存のためにフィルターを外したり別参照元へ変えたりしない |
| 抽出・通知表の記号 | 記号が必要な形式では必須。長さと保存の扱いは[記号制限表](#symbol-limits)参照 |
| 保存・再表示 | 有効範囲内の値を黙って切り詰めない。範囲超過は受付前にエラーとする |

<a id="symbol-limits"></a>
### 記号入力の制限

| 入力箇所 | 必須条件 | 最大文字数 | 不正な入力時の扱い |
| --- | --- | --- | --- |
| 成績抽出の接頭・接尾記号 | 該当位置をONにする場合は空文字不可。`※!`などの文字列を使用可能 | 数値未確定。仕様確定前に確認が必要 | 修正対象の欄にエラーを表示し、保存済み設定を維持。自動切詰めしない |
| 通知表の接頭・接尾記号 | 前後付加では空文字不可。そのまま表示・括弧では入力不要 | 数値未確定。仕様確定前に確認が必要 | 不正な記号を保存成功と表示せず、保存済みテンプレートを維持。切詰めしない |

上記2つの上限は、開発側で対応する保存経路を確認し、文字数・数え方・超過時のメッセージを確定する。未確定を無制限または1文字限定と解釈しない。確定後はこの表を更新し、入力・保存・再表示に同じ規則を適用する。

### コピー・既存データ

| 場面 | 動作 |
| --- | --- |
| 旧赤点基準 | 新ルールへ自動変換・リセット・意味変更しない。新ルール不足時の代替参照元にしない |
| 旧データを使う学校別帳票・独自処理 | 既存動作を維持。すべての独自帳票を共通3出力の対象とみなさない |
| 対応経路でのコピー・年度更新 | 項目・時期・科目・母集団・単元・式の行参照を正しく対応づけ、順序を維持 |
| 削除済みルール | コピーによって復活させない |
| 対応経路でコピーする未完成ルール | 未有効のまま保持し、自動有効化しない。入力済み参照が正しく対応づけられる場合だけ保存 |
| 対応先を特定できない | 保存できない部分を通知。同名グループで代用したり条件を外して全対象にしたりしない。不完全な設定でコピー先を上書きしない |
| 個人の判定結果・前年度の確定済み参照元 | 翌年度の新結果・新参照元としてコピーしない |
| 復元・フレーム変更・セル削除後の再作成 | 旧セル結果は無効。IDや得点が同じでも新セルに付け直さない |
| 新しい赤点情報を持たない旧設定ファイル | 旧赤点値から生成せず、現在のルールも黙って削除しない。対応する取込方式に従う |

コピー・年度更新・入出力・復元の対応範囲はリリースごとに定義する。設定移行の成功は判定実行を意味しない。集計参照を使う機能は、実データの参照元・確定済み結果・単元・精度を検証してから結合完了とする。

<a id="db-overview"></a>
## 12 — データ概要・保存関係

保存データの定義をまとめた付録。Google Sheetsでは12・13・14を独立した3つのデータタブにし、画面01–10の構成要素表へDBカラムを混在させない。画面操作を理解するためにスキーマを読む必要はない。以下は保存設計であり、DB作成・マイグレーション実行済みという意味ではない。

### データの分類

| テーブル・保存先 | 変更範囲 | 1行・1設定の意味 | 関連画面 |
| --- | --- | --- | --- |
| `red_score_settings` | 新規テーブル | 学校・年度内の評価フレーム項目に属する1つのルール | 02–04 |
| `red_score_results` | 新規テーブル | 現在の得点セルに対する結果と更新制御情報 | 06–10 |
| `grade_evaluate_frame_items` | カラム追加 | 項目のルール一覧版数。設定変更後に旧処理が上書きすることを防止 | 02–04、06 |
| `grade_publish_conf_grade_items` | カラム追加 | 公開設定・年度・項目・通常／単元区分ごとの赤点表示効果 | 08–09 |
| `grade_extract_conf.extract_setting` | 既存JSONを拡張 | 抽出設定ごとのフィルター・接頭／接尾記号・セル色 | 07 |
| 既存の通知表の表・条件保存先 | 条件を追加。専用テーブル・カラムは追加しない | テンプレートの赤点表示選択と記号文字列 | 10 |

1つの項目に複数ルールを持ち、1つのルールを複数セルに適用できる。各セルには現在有効な結果を1行保存し、3つの出力が共通で読む。表示設定は出力ごとに保存する。再判定まで維持すべき個人の結果を、ルール削除に連動して削除しない。

### セルの識別と関連

結果の一意キー：`school_id + year + evaluate_frame_item_id + group_id + student_id + tangen_id`。

| 情報 | 意味 |
| --- | --- |
| `school_id`、`year` | 学校と年度 |
| `evaluate_frame_item_id` | 評価フレーム項目。評価項目・学期／時期・得点カラムを特定 |
| `group_id`、`student_id` | 授業と生徒 |
| `tangen_id` | 通常得点は0、単元別は単元ID |
| 結果の`red_score_setting_id` | 選択したルール。選択できない場合はNULL可 |

関連と権限はアプリケーションで検証し、外部キー制約は定義しない。新規2テーブルはInnoDB・`utf8mb4`・`utf8mb4_general_ci`を使用する。本機能のために参照先の識別子や照合順序を変更しない。

### 既存テーブルへ追加する2カラム

| テーブル | カラム | 型・NULL・初期値 | 意味と用途 |
| --- | --- | --- | --- |
| `grade_evaluate_frame_items` | `red_score_revision` | BIGINT UNSIGNED／NULL不可／0 | ルールの追加・編集・削除・並べ替えと同じトランザクションで増加。判定処理の検証に使い、UI状態ラベルにはしない |
| `grade_publish_conf_grade_items` | `red_score_display_type` | TINYINT UNSIGNED／NULL不可／0 | 0：効果なし、1：括弧、2：`*`接頭、3：`*`接尾。既存行は0で既存表示を維持 |

公開効果の保存単位は`grade_publish_conf_id + year + evaluate_item_id + tangen_flg`。`tangen_flg`は通常／単元の区分であり、**個々の単元IDではない**。保存・再表示・コピー・Web／PDF出力で値を維持する。

抽出JSONは`use_target_extract`、`use_prefix_mark`、`prefix_mark`、`use_suffix_mark`、`suffix_mark`、`use_cell_coloring`、`cell_color`を使用する。通知表オプションはダイアログ操作後に「更新する」を押す既存の表保存手順に従う。

### 更新時の整合性

- 保存成功を通知する時点で最終得点と判定結果を一致させる。
- セル世代・書込み版数・ルール版数により旧処理の結果を除外する。完了時刻だけで判断しない。
- 同じ点数でも、セル削除・再作成時は新しい世代とする。ルール編集後の再判定待ちでは前回結果を維持する。
- 新処理が待機中という理由だけで前回結果を無効化しない。保存エラーを業務上の判定不可へ置き換えない。
- トランザクションとロック順の詳細は[DB設計6節](database-design.ja.md#6-同時更新の具体的な方式)を参照。これらの仕組みを画面の操作項目にはしない。

### 基準の種類別の使用データ

| 種類 | 基準値 | 式の参照元 | 計算式 | ルール単位の端数処理 |
| --- | --- | --- | --- | --- |
| 固定点数 | 基準設定完了時に必須 | NULL | NULL | NULL |
| 満点に対する割合 | 基準設定完了時に必須 | NULL | NULL | `round_flg=0/1`。有効時はtype/digits必須 |
| 計算式 | NULL | 平均使用時は一式必須。未使用時はNULL | 必須 | NULL。各計算行に保持 |

**適用条件**の参照元は`apply_condition`内に保存し、上記の式用カラムの代わりにはしない。固定点数でも、適用条件に平均点・集団得点率を使う場合は集計依存となる。

### 条件・計算式の構造

| 内容 | 主な要素 | 規則 |
| --- | --- | --- |
| `apply_condition.filters`の通常フィルター | 種類・値・種類により必要な条件キー | 同種類内OR、種類間AND。各値とキーの関係を保持し、適切に重複除去 |
| `apply_condition.aggregate_conditions` | average/group_rate、lt/lte/gte/gt、比較値、参照元 | 行同士・通常フィルターとAND。得点率の比較値は0–100 |
| 参照元 | `period_id`、`term_id`、`grade_calc_conf_id`、`population_type`、`population_ref_id` | 条件・式で共通構造を使うが、選択内容は独立して保存 |
| `formula`の各行 | 左右の値・演算子・前行参照・端数処理 | 後続行は参照行の処理後結果を使う。循環・後方参照不可 |

条件のSQL NULLは全対象を意味する。JSON null・空文字／空オブジェクト・両条件配列が空という表現で入力検証を回避しない。各TEXTの設計上限はUTF-8で60,000バイト。JSON内の小数は値を保持するため文字列で保存する。データ文字列をコードとして実行しない。

| `population_type` | 母集団 | `population_ref_id` |
| --- | --- | --- |
| 1 | 当該年度の生徒の学年 | NULL |
| 2 | 当該年度の生徒のホームルーム | NULL |
| 3 | 順位集計グループ | `grade_calc_groups.id` |
| 4 | 組み合わせグループ | `grade_calc_group_combos.id` |
| 5 | 対象セルの授業 | NULL。授業はセルから特定 |
| 6 | 科目グループ | `grade_calc_group_sub_subjects.id`。選択IDを維持し、実際の母集団を特定 |

**キー・索引：** 主キー`id`、一覧取得索引`(school_id, year, evaluate_frame_item_id, setting_status, sort_no)`。読取順は`sort_no, id`。論理削除したIDを別ルールへ再利用しない。

| `updated` | INT | 可 | NULL | 最終更新者 |

### 結果コード

| 業務上の状態 | `judgment_status` | `is_red` | 選択ルール | 理由 |
| --- | --- | --- | --- | --- |
| 未判定 | 行なし、または初回予約行のNULL | NULL | NULL | NULL |
| 赤点 | 1 | 1 | 必須 | NULL |
| 非赤点 | 1 | 0 | 必須 | NULL |
| 判定不可 | 2 | NULL | 選択できた場合に保持 | 必須 |
| 適用外 | 3 | NULL | NULL | `no_applicable_rule` |
| 得点なし | 4 | NULL | NULL | `no_score` |

有効な得点が残り、`judgment_status=1`かつ`is_red=1`のセルだけが赤点表示・抽出に寄与する。制御行があるだけでは判定済みとはいえない。`is_red=NULL`は非赤点と異なる。「再実行待ち」コードを追加して前回結果を失わせない。

判定不可の理由コード：`source_missing`（参照元不足）、`source_invalid`（参照元不正）、`membership_missing`（所属先未特定）、`membership_ambiguous`（所属の矛盾）、`maximum_invalid`（満点不正）、`condition_invalid`（条件不正）、`formula_invalid`（式不正）、`division_by_zero`（0除算）、`numeric_overflow`（桁あふれ）。UIでは業務上の説明を表示し、SQLエラーをそのまま表示しない。

### 結果の説明情報

| `judgment_context`の内容 | 目的 |
| --- | --- |
| `score`、`grade_id` | 実際に使用した得点と得点レコードの識別子を保持 |
| `threshold`、`compare_type` | 判定時の閾値と比較方法。閾値は精度維持のため既約分数の整数分子・分母で保存 |
| `maximum` | 割合計算で実際に使用した満点。未使用ならNULL |
| `sources` | 条件・式で使用した参照元。確定済み／最新、参照結果の識別子、完全な対象範囲を保持 |
| 解決した科目グループ | 選択した科目グループIDと実際に使用した種類・母集団の両方を保持。元の選択を上書きしない |

判定成功には得点・閾値・比較方法を必須とする。判定不可では特定できた情報を保持する。適用外・得点なしでは、使用しなくなった旧閾値・参照元を残さない。参照生徒の全名簿・連絡先・全履歴をこの項目に保存しない。

**キー・索引：** 主キー`id`、[12 — データ概要](#db-overview)のセル識別6項目による一意キー、読取索引`(school_id, year, group_id, student_id)`。再実行・完了要求の再送でも、結果を整合的に保存し重複させない。
