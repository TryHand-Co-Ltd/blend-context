## 1. 条件のみ保存した未完成ルール — ①

対象：[01 一覧・削除](https://www.figma.com/design/iAB9nFC3RuqxbLUMsh79jd/?node-id=6-4277)、条件／基準から一覧へ戻る経路。

- [ ] 条件のみ保存した行を「未完成」または既存の同等表示で残し、「基準設定を開く」から編集を継続できるようにする。
- [ ] 基準は未設定として示し、0を補完したり有効なルールとして表示しない。
- [ ] 画面は設定途中・無効なら一覧に残して編集、有効なら判定対象、削除済みなら非表示・対象外とする。データはsetting_statusで管理するが、カラム名や0/1/2をUIへ出さず、新しい状態選択欄・無効化／復元ボタンを追加しない。
- [ ] 中間保存→再表示→基準入力継続を示す。未完成行は優先ルール判定に参加しない。
- [ ] 未完成行の削除→一覧から消える→再読込みでも復活しないことを示す。削除前に開いた編集画面からは復活させず、取消し／保存失敗は元の状態を維持する。
- [ ] UI外の注記：「条件のみ保存した未完成ルールは一覧に残り、編集を続けられます。削除したルールは一覧に表示せず、判定対象にも含めません。」
- [ ] 有効なrule削除後は次回判定まで前回結果を保持する説明を残す。点数削除とは分ける。

## 2. AND/ORの説明 — ②

対象：[02](https://www.figma.com/design/iAB9nFC3RuqxbLUMsh79jd/?node-id=6-3582)の02-A／02-B両方、条件追加欄のhelperと外側注記。

- [ ] 対象フィルターと平均点／集団得点率の説明を分ける。既存form内の見出しや2文で示し、任意のAND/ORエディターは追加しない。
- [ ] 対象フィルター：「対象フィルターは、同じ種類のいずれか1つ、異なる種類はすべて満たす必要があります。」
- [ ] 集計条件：「平均点・集団の得点率の条件は、同じ種類でもすべて満たす必要があります。対象フィルターともANDで組み合わせます。」
- [ ] **UI外**に注記する場合は「平均点・集団の得点率の条件はANDで組み合わせます。」と設計を直接説明する。提出mockupには指摘経緯や回答待ちを入れず、確認済みの根拠はcontext内で管理し、以前の回答待ち表示をcanvasに残さない。
- [ ] 同じ参照元でA≥50、A<70を指定：40／70は不成立、50／60は成立。40をORで対象にする例を混在させない。
- [ ] 02-A／02-Bまたはrule説明に「これらのAND／ORは1つの赤点ルール内の条件に適用します。複数の赤点ルールは優先順位に従い、最初に適用条件が一致したルールを使用します。ルール同士をANDで結合しません。」を追加する。01-Bの優先順の説明とも一致させる。
- [ ] 複数ruleの例：両方の条件が一致し、優先1のT=20、優先2のT=30、S=25、未満ならrule 1を使い非赤点。30を採用したり、全ruleの同時一致を求めたりしない。
- [ ] guide／複製helperにも同じ区別を適用する。条件と計算式の参照先の独立性は維持する。

- [ ] 別に「ルールの変更・削除だけでは前回結果を保持し、次回判定で更新します。」と示す。

## 4. 同じ例の端数処理 — ④

対象：[03-C](https://www.figma.com/design/iAB9nFC3RuqxbLUMsh79jd/?node-id=6-2346)、[01-B](https://www.figma.com/design/iAB9nFC3RuqxbLUMsh79jd/?node-id=6-4277)、03-C外側の説明。

- [ ] 同じ「平均60点未満」ルールで、式1は平均÷2、**端数処理あり・小数第1位・切り捨て**。式2は式1の結果×0.8、**端数処理なし**。第1位を処理するとは整数にすることであり、小数1桁保持ではない。
- [ ] 一覧・編集・説明すべてで49.7÷2=24.85→24→24×0.8=19.2を示す。S=19.1の未満判定は赤点。
- [ ] 閾値19の設定を同じruleの保存前後として残さない。比較用に残す場合は「式2だけ丸める別設定」と明示し、非赤点と示す。比較記号や生徒点数の丸めで差を隠さない。
- [ ] 保存／再表示の関連prototypeがあれば各行の選択を維持し、一覧要約は保存内容と一致させる。
- [ ] 「ホームルーム平均」がオペランド列に収まり演算子に重ならないよう列幅／折返しを調整する。長い母集団名、行高、clippingを確認しfontは維持する。
- [ ] 修正はこの例に適用し、他の式の各行で端数処理を選べる仕様は維持する。
