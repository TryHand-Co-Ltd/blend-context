# 赤点 — 受入条件

**更新日:** 2026年9月28日。

赤点の設定・判定・結果表示に関する受入条件です。

`S`＝最終保存点、`M`＝現在の実効満点、`A`＝参照集計の丸め前平均、`R`＝同集計の丸め前の集団得点率、`T`＝選択した端数処理後の基準。集計条件・式は、その種類を採用する実装回に適用する。

## 権限・対象・設定

- [ ] **AC-G01 — 操作権限とデータ範囲:** 通常教員も機能アクセス権と対象項目の編集権があれば設定できるが、項目編集権だけで一括実行権は得ない。画面・保存・削除・並べ替え・参照元選択で学校／年度／項目／授業／単元の権限を検証し、登録・抽出・公開・通知表は各機能の権限を守る。ID改変による拒否時は設定・点数・結果を変えない。
- [ ] **AC-G02 — 対象の入力型:** 整数・小数・単元の数値項目を判定し、A/B/Cや合否の選択型を直接判定しない。選択型の既存フィルタは数値項目の適用対象を絞るために利用できる。
- [ ] **AC-G03 — セルの識別:** 結果は生徒・学校・年度・授業／科目・項目・学期／時期・単元に対応し、同名項目や別単元を混同しない。削除後に再作成したセルへ旧結果を付け直さない。
- [ ] **AC-G04 — 複数設定の保存と再表示:** 一覧は項目・型・時期を示し、ルールなしでは未設定表示と追加操作を提供するが、旧値や「30未満」のルールを自動作成しない。複数ルールの適用条件・基準設定を編集し、名称・順序・条件・基準・比較・端数処理・要約を保存どおり再表示する。名称変更で関連を切らず、取消し／保存失敗では保存済み設定と結果を維持する。
- [ ] **AC-G05 — 適用対象と参照元の必要性:** 全対象も許可範囲内とし、対応する教科／科目・学年・学級／グループ・選択フィルタは同種類内OR、種類間ANDで組み合わせる。条件か基準が平均／率を使えば参照元を必須とし、欠損時に条件を外さない。両方独立なら不要な参照元欄を表示・必須化しない。
- [ ] **AC-G06 — 優先順の最初の一致:** 最初に一致するルールを選んでから計算し、基準の厳しさで選び直さない。適用の可能性がある上位条件が不明、または選択済みルールが計算不能なら、下位へ進まず判定不能とする。非集計フィルタだけで対象外が確定すれば、そのルールの集計は不要。

## 基準・満点・数値精度

- [ ] **AC-G07 — 比較境界と警告:** 未満は `S=T` を含めず、以下は含め、`S` を丸めて判定しない。情報が十分な場合の0／満点警告も最終 `T` と比較に従い、値を変えず、`A−0` を基準0と誤表示しない。
- [ ] **AC-G08 — 固定点数:** 保存時と対象拡大時に全対象で `0≤N≤M` を検証し、不適合なら代用・自動補正せず拒否する。一度正常保存した固定値は後日の満点変更でも `T=N` のままで、条件も独立なら平均や正の満点を計算の前提にしない。
- [ ] **AC-G09 — 現在の実効満点:** 標準→有効な単元例外→実際に適用する授業選択の順で解決し、単元例外がなければ適用可能な標準を使う。選択肢の定義・コード、最高実得点、集団総満点、無条件の100、確定済み集計時の満点で代用しない。
- [ ] **AC-G10 — 得点率:** 入力は0〜100、基準は `M×N/100` に選択した端数処理を適用し、既定は処理なし。実行時の `M` が0・負・非有限・解決不能なら判定不能とし、代替値から結論を作らない。
- [ ] **AC-G11 — 数値の保持:** 公表した入力範囲内の値を保存・再表示で切り詰めず、`S=T` を正しく比較する。非数・無限値・範囲超過は拒否し、実行時overflowを赤点／非赤点に変換しない。

境界例は上の規則の一部であり、別々のACには分けない。

| 規則 | 条件 → 結果 |
| --- | --- |
| 優先順位 | 両方適用する優先1 `<20`／優先2 `<30`、`S=25` → 非赤点 |
| 満点の上書き | 標準100・単元40・授業選択50 → 50。授業選択なし → 40 |
| 得点率の端数 | `M=75`・30%・`S=22.2`・未満 → 処理なし22.5なら赤点、整数切り捨て22なら非赤点 |
| 現在の満点 | 現在50・集計時100・30%・`S=20`・未満 → `T=15`、非赤点 |
| 0／満点の境界 | 非負点数で `T=0`・未満は誰も含めず、以下は0点を含む。`T=M`・未満は満点を含めず、以下は含む |

## 集計元と式

- [ ] **AC-G12 — 参照する集計の範囲:** 集計対象時期・順位集計設定・集計対象（母集団）と科目／項目／単元を一致させ、抽出生徒の絞込みで母集団を変えない。条件と式はそれぞれ保存した参照元を使い、一方の編集で他方を変更せず、同一処理で同じ参照元の異なる時点を混ぜない。
- [ ] **AC-G13 — 確定済み優先と欠損:** 該当範囲の有効な確定済み集計を優先し、存在しない場合だけ最新の完了済み集計を使う。選択済みソースの欠損や適切な集計の不在は判定不能とし、別時期／母集団／通常集計、未集計点、0で埋めず、確定済みを無視する選択肢も設けない。
- [ ] **AC-G14 — 丸め前の整合した集計値:** 平均・率の分岐には丸め前の値を使い、平均は同集計の得点人数（順位対象人数ではない）、率の分子／分母は同じ寄与集合を使う。平均49.99は表示50でも `<50` 側で、後続の端数処理は分岐を変えず、人数0・不正な総満点・対応不明は判定不能とする。
- [ ] **AC-G15 — 既存の集団得点率:** 既存順位集計の総得点／総満点を使い、個人率の平均や対象生徒の満点で計算し直さない。異なる満点が混在しても専用計算・設定禁止を追加せず、その違いだけで停止しないが、不正データは正常扱いにしない。
- [ ] **AC-G16 — 行ごとの式と端数処理:** 採用した式は四則演算の行で構成し、自由記述の式・script・任意関数は提供しない。前行参照は端数処理後の値、最終行は `T` とし、表示用短縮値を使わず、点数の書込み・NULL化・min/max補正を行わない。
- [ ] **AC-G17 — 式の保存検証:** 一つ以上の完全な行を要求し、欠けた値・固定の0除算・自己／後続／削除済み行参照を拒否する。行の削除・並べ替えで、同じ番号になった別の式へ参照を黙って付け替えない。
- [ ] **AC-G18 — 負の基準:** 有限で正しく計算した負の `T` は有効で、0へ補正せず通常比較する。`T=−5` なら非負点数は非赤点、負数を許す項目の−6は未満で赤点、−5は以下でのみ赤点となる。

集団の60/100と80/100は70%となり、65%以上に一致する。式 `A÷2` → 0.8倍で `A=49.7` の場合、1行目を整数へ切り捨てれば19.2、処理なしなら19.88となる。

## 点数と結果の更新

赤点の記号・絞込みは有効な赤点結果だけに適用し、結果がないことを赤点や合格とみなさない。

- [ ] **AC-G19 — 判定する最終点数:** 計算・制限・関連更新後の保存値を使い、手入力・見込点・未受験の数値・有効な0を、AutoRatingや順位対象かどうかに関係なく判定する。見込点と赤点は別状態とし、空欄／NULL／削除／非使用を0にせず、失われた点数の旧記号・絞込みを停止して既存の空欄表示を守る。
- [ ] **AC-G20 — 実行後の状態:** 赤点／非赤点／未判定／判定不能／適用なし／点数なしを区別し、未判定・判定不能を合格としない。点数を維持したまま、実行結果を正常保存した時点で下表の規則に従って旧結果を停止する。

| 実行結果 | 現行結果とその後の扱い |
| --- | --- |
| 十分な情報から全ルールが対象外 | 適用なし。旧記号・絞込みを停止し、基準を満たした合格とは扱わない |
| 必要な参照／値の欠損、0除算、非有限値などで基準を作れない | 判定不能。旧結果を現行として使わず、下位ルール・別ソース・0・旧赤点で代用しない |
| 原因修復後、設定やソースだけを保存 | 新しい判定はまだない。再実行成功後に赤点／非赤点へ更新する |

- [ ] **AC-G21 — 再実行前の保持と最後の削除:** 基準・比較・式・順序・対象・ソース・集計の変更、または最後のルール削除だけでは、前結果と保存済み表示設定・効果を維持する。保存と判定完了を区別して再実行を案内し、次の登録／一括実行でルールなしと確定した後に適用なしへ更新する。公開表示もルール件数だけで記号を即時削除しない。
- [ ] **AC-G22 — 共通結果と更新順:** 三出力は同じセルの有効結果を読み、同一条件の再実行は同じ結果となり、結果・記号を重複させない。遅れた旧処理が新しい点数／設定による結果を上書きせず、異なる時点の点数と判定を成功結果として混在させない。

例: 中間120を100で保存したら100、手修正28→35なら35を使う。32が `<30` で非赤点のとき、`<35` の設定保存だけでは変えず、再判定成功後に赤点となる。

## 登録・一括実行・失敗

- [ ] **AC-G23 — 登録と再実行の対象:** 対応する直接入力・CSV・試験連携・一括処理で、許可された授業／時期／生徒と実際に更新された関連セルを判定する。AutoRatingなし・手入力skip・連携後の計算skip・赤点ルールのみ・最後のルール削除後を取りこぼさず、無関係な全校再判定へ広げない。

| AC-G23の実行条件 | 必須の結果 |
| --- | --- |
| 実行方法 | 赤点専用の手動／自動モードは設けず、登録と既存の一括計算に従う |
| 同一処理に参照依存セルと独立セルがある | 参照元がないセルは判定不能でも、固定基準などで独立して判定できる別セルは処理する。同じセルで下位ルールを試す意味ではない |

- [ ] **AC-G24 — 満点／単元変更の起動条件:** 定義や入力欄の最大値保存だけでは全点数を即時再判定せず、授業登録・利用可能で権限のある満点一括設定は既存計算の成功後に結果を更新する。単元の点数削除／非使用では旧結果を停止し、計算側の単元対応を全設定画面で単元選択できる根拠にはしない。
- [ ] **AC-G25 — 相対評価の実行順:** 自動順位集計を「実行しない」にし、入力完了→「集計実行」完了→「自動算出実行」完了の順で更新する。登録時判定と確定済みソース優先は維持し、計算で参照点が変わっても自動収束ループは追加しない。
- [ ] **AC-G26 — 保存成功と安全な通知:** 直接入力・CSV・連携の既存transaction境界で点数と結果を整合させ、保存失敗を判定成功や旧結果失効済みと通知しない。保存済み・未更新・判定不能・失敗を区別して対応を案内し、内部エラー・権限外情報を露出せず、名称・記号をコードとして実行しない。
- [ ] **AC-G27 — 一括の部分完了:** 更新済み・判定不能・技術的失敗の範囲を区別し、queue投入や授業カウンタだけで全セル成功と表示しない。部分完了を全件rollbackと偽らず、失敗範囲を修復して再実行できる。
- [ ] **AC-G28 — 閲覧・出力は再判定しない:** 未判定・判定不能・再実行待ちだけで抽出・公開・通知表を禁止せず、各機能の権限・日程・非表示を守る。閲覧・Excel・公開・再印刷は集計や判定を起動しない。

## 三つの出力

- [ ] **AC-G29 — 成績抽出の絞込み:** フィルタON時だけ、指定科目・項目・時期・単元内に有効な赤点が一つ以上ある生徒を残す。範囲外の赤点で採用せず、0件を正常扱いとし、他のフィルタの意味を維持する。
- [ ] **AC-G30 — 成績抽出のセル表示:** 前／後記号と既存paletteの色を赤点セルだけに適用し、記号ONなら入力を必須とし、前後を併用できる。装飾だけでは生徒を絞らず、隠れた点数を復元せず、失効／空欄に旧効果を残さず、例示色を全templateへ強制しない（24に前 `※`・後 `!` → `※24!`）。
- [ ] **AC-G31 — Excelの一致と信頼元:** 同じ出力の画面と実Excelで対象・記号・色・空欄・値を一致させる。送信された赤点flagや閾値の改変で、server側の結論・許可範囲を変更できない。
- [ ] **AC-G32 — 公開設定と非表示:** 設定可能な赤点項目の通常／単元範囲で括弧・固定 `*` の前／後を保存・再表示でき、任意文字・赤点生徒filter・専用背景は追加しない。非表示の点数や状態を記号で漏らさず、赤点失効後も見込点など他の有効な効果・背景・書式を維持する。
- [ ] **AC-G33 — 公開の効果合成:** 見込点と赤点の異なる効果は組み合わせ、同じ効果は一度だけ適用する。括弧＋前 `*` は `(*24)`、前 `*` 同士は `*24`、括弧同士は `(24)`、前後 `*` は `*24*` とする。
- [ ] **AC-G34 — 公開の本人・期間・出力:** 生徒／保護者は本人関係・学校・年度・公開日程の許可範囲だけを閲覧できる。生徒側web、関連API、公開PDFで同じセルの状態・表示・非表示を一致させる。
- [ ] **AC-G35 — 通知表の表示選択:** 赤点は、そのまま表示・カッコ付き・前文字列・後文字列を選べ、前／後だけ文字列を必須とする。赤点用の非表示・斜線・背景は追加せず、既存条件のそれらの機能は維持する。
- [ ] **AC-G36 — 通知表の最初の一致:** 既存の非表示／時期制御後、特定科目→既存順のcheckbox→赤点→空欄→通常表示とし、最初の一致で止める。そのまま表示でも下位へ進まず、後方の非表示条件を探し直さない。上位の見込点が括弧なら `(24)`、そのままなら `24` で、赤点の `※` を加えず、非表示／斜線も解除しない。
- [ ] **AC-G37 — 通知表の保存・コピー・PDF:** ダイアログ完了後、表の「更新する」で保存し、赤点だけの設定でも選択・文字列を再表示／templateコピーで維持するが個人結果はコピーしない。保存・再表示後と状態更新後の実PDFは正しい科目／時期／単元と条件順を使い、空欄の旧記号、記号欠落、はみ出し、既存構造の変更を生じさせず、全通知表の凍結／version管理を追加しない。

## 旧機能・設定移行・実装範囲

- [ ] **AC-G38 — 旧赤点の保全:** 旧閾値を新ルールへ移行・意味変更・resetせず、新ルールなし／不一致／欠損の代用にもしない。学校別帳票、コピー、年度継承、入出力、復元、同期で旧値の既存の扱いを維持する。
- [ ] **AC-G39 — 移行先へ旧結果を流用しない:** 設定同期だけで判定完了とせず、復元／フレーム置換で消えたセルの結果を新セルへ付け直さない。対応する設定移行でも、旧年度の確定済み集計や個人結果を新対象の結果として流用しない。
- [ ] **AC-G40 — 実装回の範囲:** 種類・条件／式・学校／権限・登録経路・設定移行経路を明記し、未対応を有効機能として表示しない。採用した範囲は設定→判定→保存→三出力まで完成させ、集計を使う処理は実際の集計データで確認する。

## 設計詳細

以下の設計案は受入条件を補足するもので、各回の実装対象となる機能範囲に応じて適用します。

| 対象 | 設計案 |
| --- | --- |
| 追加・切替 | 新規は末尾、固定点数・未満・値未入力。不完全なルールは無効、空の限定filterはエラー。同一編集内は種類別入力を一時保持し、再表示は保存した種類だけを復元。全種類の履歴は作らない |
| 条件・式 | 分岐は `<`／`≤`／`≥`／`>`、式は平均・固定値／係数・前行結果、平均は式内で一つの参照元。式とoperandは各回の実装範囲に従う |
| 端数UI | 式も既定は処理なし。位置 `p=1..9`、初回ONは1、残る桁は `p−1`。方法未選択なら保存不可。四捨五入は半分を0から遠ざけ、上／下はceil／floor（−5.2→上−5／下−6、−5.5→四捨五入−6） |
| 初期表示・文言 | 抽出の新filter／効果OFF、公開は効果未設定、通知表はそのまま表示。再実行の必要性、データ欠損の理由、エラー時の未更新範囲を明示する |
| 入力上限 | 精度、桁数、名称長、係数範囲、行数上限は技術設計で定義する。境界比較・有限性・無断切詰め禁止はAC-G11を維持 |
| 設定移行 | 実装範囲の項目／時期／科目／母集団／単元／式行を対応付ける。対応不能なら有効化せず通知する案とし、旧形式の新部分欠落や更新／rollback範囲は対応する経路に応じて扱う。legacyから作成せず、現行ruleを黙って削除しない |
