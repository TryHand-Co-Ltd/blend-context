# DEC-003 — 条件保存後の遷移（基準未入力時は基準設定へ）

日付：**2026年10月7日**。対象：RC-001。根拠：担当者確認「条件（フィルター）だけ先に保存し、基準画面をまだ保存していない場合は、基準入力画面へ進む」。

| 項目 | 内容 |
| --- | --- |
| 決定 | 適用条件を保存したとき、基準が未入力（未完成／新規ウィザード）なら基準設定へ進む。基準が既に完成し一覧から編集している場合は一覧へ戻る |
| 置き換える定義 | [画面定義 v2 §03 No.15](../docs/v2/screen-definition.ja.md) の旧文「条件を保存して一覧へ戻る」 |
| 影響 | TC-RS-FUNC-004 の期待結果1を更新。実装（`RedScoreSettingController::conditionStore`）と一致 |
| 状態 | 確認済み（チャット内の明示指示）。顧客文書への再提出要否は別途 |

## 理由

新規ルールは条件→基準の二段入力である。条件だけ保存して一覧へ戻すと、未完成行の基準入力が途切れやすい。基準未入力時は基準設定へ続ける。
